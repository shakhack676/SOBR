# Créditos de imagens

Todas as imagens em `public/images/` são **ilustrativas** e foram obtidas no Wikimedia Commons. Não representam membros, operações ou equipamentos reais do СОБР.

Antes de reutilizar o projeto comercialmente, confirme a licença de cada arquivo na página de origem. Fotos de forças armadas dos EUA normalmente são de domínio público; imagens de outros países podem estar sob CC BY, CC BY-SA ou equivalente.

## Como localizar

Pesquise o título entre parênteses no Wikimedia Commons ou use a URL original registrada no histórico do projeto. Ao substituir uma imagem, atualize esta tabela.

## Tratamento

As imagens foram redimensionadas para no máximo 1600 px de largura e convertidas para WebP (qualidade 78) com `sharp`. O tratamento de cor (grayscale, brilho, contraste) é aplicado via CSS, preservando o arquivo original convertido.
